# Football Match Predictor Web Application

A full-stack web application that presents **English Premier League football match predictions** generated by a separate machine learning pipeline.

## The application provides an interactive interface for viewing upcoming fixtures, football teams and predicted match outcomes. It was developed using **React, Spring Boot, Java and MySQL** as part of an AI-powered football match prediction project.

## Project Overview

This repository contains the **web application component** of the Football Match Predictor AI project.

The machine learning pipeline is responsible for collecting football data, preprocessing it, engineering features, training models and generating predictions.

This web application is responsible for:

* Retrieving prediction data from the backend
* Displaying upcoming fixtures
* Allowing users to select matches
* Showing the predicted outcome
* Displaying available teams
* Providing access to fixtures through an interactive interface

The application was designed to provide users with a simple way to access predictions for upcoming Premier League fixtures.

## System Architecture

```text
Football Match Predictor ML
            ↓
      Generated Predictions
            ↓
        MySQL Database
            ↓
      Spring Boot Backend
            ↓
       REST Endpoints
            ↓
       React Frontend
            ↓
           User
```

The project uses React for the frontend, Spring Boot with Java for the backend, and MySQL for database management.

---

## Frontend

The frontend was developed using **React** and provides several pages for interacting with the football prediction platform.

### Main Pages

* **Home** — project homepage
* **Prediction** — view and select upcoming matches and their predictions
* **Fixtures** — view available fixtures
* **Teams** — view available teams
* **Login** — user login page
* **Register** — user registration page

React Router is used to manage navigation between the different pages.

### Prediction Page

The main prediction page retrieves future fixtures from the Spring Boot backend using:

```text
GET /matches/future-fixtures
```

Users can select an upcoming match and view the prediction returned by the system.

The application focuses on predictions for the **next gameweek**, reflecting the project design decision to use recent information when generating predictions.

---

## Backend

The backend was developed using **Spring Boot and Java**.

The application follows a layered structure consisting of:

```text
Controller
    ↓
Service
    ↓
Repository
    ↓
Database
```

### MatchController

The main controller provides endpoints for retrieving prediction and fixture information.

```text
GET /matches/future-fixtures
GET /matches/teams
GET /matches/allFixtures
```

### MatchService

The service layer handles the application logic for retrieving:

* Upcoming prediction matches
* Available teams
* Fixture information

For prediction matches, the service uses a date range covering the current date and the following week.

### MatchRepository

The repository uses **Spring Data JPA** to communicate with the database.

It provides queries for:

* Retrieving upcoming home fixtures
* Retrieving distinct teams
* Retrieving all home fixtures

---

## Database

**MySQL** is used as the database management system.

The database stores the football match and prediction information used by the Spring Boot backend.

The application retrieves the stored information through Spring Data JPA before returning it to the React frontend.

---

## Prediction Flow

```text
1. Machine learning pipeline generates predictions
                    ↓
2. Prediction data is stored in MySQL
                    ↓
3. React requests upcoming fixtures
                    ↓
4. Spring Boot receives the request
                    ↓
5. MatchService processes the request
                    ↓
6. MatchRepository queries MySQL
                    ↓
7. Prediction data is returned to React
                    ↓
8. User views the prediction
```

The machine learning and web application components were designed as connected parts of the overall football prediction system.

## Related Machine Learning Repository

The predictions displayed by this application are generated by the separate machine learning repository.

**Machine Learning Repository:**

`football-match-predictor-ml`

The ML repository contains the data scraping, preprocessing, feature engineering, model training, evaluation and prediction-generation components.

The overall project compares **XGBoost, Random Forest and Multi-Layer Perceptron** models, with XGBoost selected as the final model based on its evaluation results.
